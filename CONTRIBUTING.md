# Contributing to GhostPart

Thanks for helping turn a promising demo into a tool that fixes real things.

## Good first contributions

- A reproducible bug in calibration, STL export, or phone capture.
- A real flat-part repair with photos, independent measurements, and fit outcome.
- Browser or device compatibility findings with model and OS/browser versions.
- An accessible improvement to the capture and measurement flow.

Before opening a pull request, run `npm test` and `npm run build`. Keep changes focused and explain what physical measurement or user workflow they improve.

For repair cases, include a scale reference, the mating geometry, manual measurements, generated dimensions, printer/material/settings, and whether the print fit. Do not post photos containing addresses, faces, financial cards, or other personal information. Safety-critical repairs are out of scope.
